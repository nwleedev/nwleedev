# 개인 메모 앱의 Independent Work 선정 요구사항

`apps/notes`에 개발자 소개 사이트 `apps/entry`의 Independent Work에 추가할 가치가 있는지 판단한다. 실제 목적, 성과와 기여를 근거로 확인하고 이력서나 포트폴리오에 사용할 내용을 검토 문서와 플랜에 정리한다.

## 필요한 결과

- `apps/entry`의 역할, 개발 의도와 기존 Independent Work의 선정 기준을 확인한다.
- `apps/notes`에서 이력서나 포트폴리오에 작성할 가치가 있는 성과와 기여를 찾아 추가 권고 또는 보류의 이유를 제시한다. 추가를 전제하지 않는다.
- `apps/notes`의 변경 커밋을 하나씩 파악해 경쟁력 있는 내용인지 평가한다. 기록만으로 판단할 수 없는 목적, 성과와 기여에 필요한 정보는 확인한다.
- 프로젝트 경험을 이력서나 포트폴리오에 작성하는 방법을 조사하고 검토 문서와 플랜에 반영한다.
- 구현 방법의 상세 설명을 피하고 목적, 성과와 문제 해결을 판단할 수 있는 내용을 작성한다.

## 완료를 확인할 자료

사이트의 역할과 메모 앱의 평가, 성과 후보의 근거, 소개 문구 제안과 평가에 따른 후속 절차를 기록한 문서와 플랜이 있다. 조사와 문서 작성은 작업용 워크트리 브랜치에서 진행한다.
