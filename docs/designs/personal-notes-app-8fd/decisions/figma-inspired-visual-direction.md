# 이전 시각 방향의 대체 기록

이 문서가 정했던 Figma식 frame, 밝은 목재 캔버스와 굵은 붉은 선택선은 새 UI의 기준으로 사용하지 않는다. 현재 시각 방향은 [집중형 텍스트 유틸리티 작업 화면 결정](focused-text-utility-workspace.md)을 따른다.

## 유지되는 결정

- 제목, 본문, 버튼, 입력과 상태 문구에 Pretendard를 사용하고 크기와 굵기로 정보 위계를 구분한다.
- 메모 화면의 왼쪽 사이드바를 두지 않고 자유 배치 작업 영역을 우선한다.
- 키보드 포커스, 선택과 drag 상태를 색 하나에만 의존하지 않고 서로 구분한다.
- 아이콘 버튼의 접근 가능한 이름과 네이티브 입력 의미를 유지한다.

## 대체되는 결정

- route에 따라 달라지는 위쪽 및 왼쪽 탐색은 한 줄 application bar와 반응형 주 헤더 원칙으로 대체한다.
- 목재 무늬, 노란 메모, 짙은 탐색 영역과 물체 이름 중심 색 토큰은 따뜻한 중립색 canvas, 흰색에 가까운 surface와 역할 기반 토큰으로 대체한다.
- 굵은 붉은 선택선은 `#EE5165` accent를 제한적으로 사용하는 selection과 별도 `focus-visible` 상태로 대체한다.
- 메모의 짧은 헤더와 상시 관리 버튼은 이동 핸들, 바로 보이는 복사와 더보기로 대체한다.

## 영향

기존 자료 저장, 자유 배치, 편집, 개별 복사, 일괄 복사와 반응형 표현은 유지한다. 실제 구현 순서와 검증은 [계획의 UI 디자인 재구축](../plan.md#ui-디자인-재구축)과 [`apps/notes/DESIGN.md`](../../../../apps/notes/DESIGN.md)를 따른다.
