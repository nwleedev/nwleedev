# 메모 선택과 오른쪽 속성 패널 결정

넓은 공간형 화면에서는 `Tab`으로 도달하거나 헤더를 클릭한 메모 하나를 선택하고, 얇은 붉은 테두리로 선택을 표시한다. 선택한 메모의 X, Y, 너비와 높이는 오른쪽 속성 패널에서 바꾼다. 입력은 `blur`, 패널 밖 클릭 또는 `Enter`에서 같은 적용 동작을 실행하며, 메모 가장자리와 꼭짓점의 직접 크기 조절도 유지한다.

## 결정 질문과 요구 결과

[메모 선택 및 속성 편집 요구사항](../requirements.md#반드시-지킬-조건)은 마우스를 사용하기 어려운 사용자가 키보드로 메모를 선택하고, 메모마다 설정 UI를 반복하지 않은 채 선택한 메모의 위치와 크기를 바꿀 수 있게 한다. 메모 본문의 상시 편집, 헤더 이동, 직접 크기 조절과 선택 및 패널 입력이 서로 충돌하지 않아야 한다.

## 검토한 선택지

- 메모마다 X, Y, 너비와 높이 입력을 두면 메모 표면이 텍스트 중심이어야 한다는 요구를 다시 위반한다.
- 가장자리와 꼭짓점 drag만 유지하면 키보드로 정확한 수치를 입력할 방법이 없다.
- 선택한 메모의 속성만 오른쪽 패널에 표시하면 메모 표면을 단순하게 유지하면서 같은 위치에서 수치 값을 편집할 수 있다.
- 포커스와 선택을 같은 테두리 하나로 표현하면 속성 패널로 포커스를 옮겼을 때 어떤 메모를 편집하는지와 현재 키보드 위치를 구분할 수 없다.

## 결정 이력

- 이전 결정은 메모 표면의 숫자 geometry 제어를 제거하고 네 가장자리와 네 꼭짓점 drag로만 크기를 바꾸는 것이었다.
- 후속 요구는 마우스를 사용하기 어려운 사용자가 `Tab`과 헤더 클릭으로 메모를 선택하고, 오른쪽 패널에서 크기와 좌표를 바꾸도록 했다.
- 이 변경은 메모 표면에 설정 UI를 되돌리지 않는다. 직접 resize와 별도로 선택한 메모의 수치 geometry를 편집하는 방법을 추가한다.
- 선택 표시는 얇은 붉은 테두리로 승인됐고, 키보드 포커스는 접근성 기준에 따라 별도 표시를 유지한다.

## 승인된 결정과 이유

- 한 번에 메모 하나만 속성 편집 대상으로 선택한다.
- 키보드 Tab 순서가 메모의 선택 지점에 도달하면 그 메모를 선택한다. 헤더의 아이콘이 아닌 부분을 클릭해도 같은 메모를 선택한다.
- 헤더 click은 메모 원문 개별 복사나 일괄 복사 항목 추가를 실행하지 않는다. 헤더 drag는 선택을 유지하면서 위치를 바꾼다.
- 선택한 메모에는 얇은 붉은 테두리를 표시한다. 선택 테두리는 포커스 외곽선을 대신하지 않으며 고대비 환경에서도 선택과 포커스를 각각 구분할 수 있어야 한다.
- 속성 패널로 포커스를 옮겨도 메모 선택을 유지한다.
- 오른쪽 속성 패널의 현재 범위는 작업 공간 좌표 X와 Y, 너비와 높이다. 회전, 정렬, 비율 잠금과 수식 입력은 포함하지 않는다.
- 필드 입력은 저장된 geometry와 분리한 초안이다. `blur`, 패널 밖 클릭과 `Enter`는 같은 적용 명령을 사용하고, 유효하며 실제로 달라진 값만 한 번 저장한다.
- 유효하지 않은 초안은 메모 geometry를 바꾸지 않고 오류가 난 필드에서 수정할 수 있게 표시한다.
- 속성 패널에서 적용한 geometry 변경은 전체 revision만 증가시키고 content revision을 바꾸지 않는다.
- 가장자리와 꼭짓점 drag에 의한 직접 크기 조절을 계속 제공한다. 메모 표면에는 숫자 입력, 단계 조절 또는 설정 버튼을 추가하지 않는다.

[메모 선택, 속성 편집과 제거 복구 조사](../references/note-selection-properties-and-removal-research.md)는 Figma의 객체 선택 및 오른쪽 속성 영역과 WAI의 포커스 및 선택 구분을 현재 화면에 적용할 근거를 기록한다.

## 예상 결과와 계획 영향

U2는 선택, geometry 입력 초안과 적용 결과를 표현할 자료를 정하고, U4는 붉은 선택 테두리, 별도 포커스 표시와 오른쪽 패널의 공통 외형을 만든다. U5는 헤더 click 및 Tab 선택, X, Y, 너비 및 높이 입력과 geometry 저장을 연결한다. 순수 입력 검증과 revision 불변 조건은 TDD로 개발하고, 실제 Tab 순서, click, drag, `blur`, 패널 밖 클릭과 `Enter`는 브라우저에서 확인한다.

## 다시 검토할 조건

- Tab 순서가 메모 본문이나 헤더 아이콘에 도달하지 못하게 하는 경우
- 붉은 선택 테두리와 키보드 포커스를 구분할 수 없는 경우
- 패널 밖 클릭이 같은 값을 두 번 저장하거나 새 메모 선택을 잃게 하는 경우
- 일괄 복사 패널과 속성 패널의 동시 사용 규칙이 정해지지 않아 메모 작업 영역을 예측할 수 없게 만드는 경우
- 속성 입력 허용 범위와 잘못된 입력 처리가 정해지지 않은 경우
