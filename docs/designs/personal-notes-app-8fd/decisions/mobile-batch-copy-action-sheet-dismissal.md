# 모바일 일괄 복사 액션 시트의 배치와 닫기

## 결정

좁은 화면의 일괄 복사 확인 및 저장 목록 관리에서 항목 동작을 화면 아래에서 열리는 모달 액션 시트로 표시한다. 상단 닫기 버튼, 시트 바깥 누르기, 기기 뒤로가기 또는 `Escape`는 항목을 실행하거나 자료를 바꾸지 않고 시트만 닫는다. 이동, 복제 또는 삭제를 실행하면 시트가 자동으로 닫힌다. 닫은 뒤에는 실행 버튼으로 포커스를 돌리고, 삭제로 버튼이 사라졌다면 남은 항목의 버튼 또는 목록 시작 지점으로 돌린다.

## 검토한 방식과 이유

[Android의 모달 시트 안내](https://developer.android.com/develop/ui/compose/components/bottom-sheets)는 화면 아래에서 명령을 제공하고 바깥 누르기의 닫기 요청을 처리한다. [HTML `dialog` 표준](https://html.spec.whatwg.org/dev/interactive-elements.html)은 모달을 열 때 뒤쪽 화면을 비활성화하고 `cancel` 및 `close`로 닫기 수명을 다루며, [WAI의 모달 대화상자 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)은 보이는 닫기 제어와 포커스 복귀를 권장한다. 버튼 옆 팝오버는 좁은 목록에서 동작 영역을 확보하기 어려우므로 유지하지 않는다. 닫기 버튼만 허용하는 방식은 기기 뒤로가기와 바깥 누르기에 익숙한 조작을 막으므로 채택하지 않는다.

시트의 높이는 내용에 맞추되 보이는 화면보다 커지지 않게 하고, 너비는 현재 화면에서 사용할 수 있는 영역을 따른다. 항목을 구분할 때 기존 목록의 항목 이름을 사용한다. 이는 픽셀 크기나 새로운 항목 이름을 요구사항으로 고정하지 않기 위한 구현 선택이다.

## 영향과 다시 검토할 조건

[완성 계획](../plan.md)의 모바일 확인과 저장 목록 관리 화면에 같은 시트를 사용한다. 넓은 화면의 팝오버, 이동 명령, 작업 초안과 저장 자료는 바꾸지 않는다. 화면 키보드, 브라우저 도구 모음 또는 safe area 때문에 마지막 동작을 실행할 수 없거나 닫은 뒤 포커스를 찾을 수 없다면 배치와 포커스 처리 방식을 다시 검토한다. 애니메이션을 지원하지 않는 브라우저에서도 열기와 닫기 및 명령 실행은 계속 동작해야 한다.
