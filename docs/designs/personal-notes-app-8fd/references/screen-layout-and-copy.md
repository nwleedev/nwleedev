# 화면별 텍스트 카피 후보

이 문서의 문구는 데스크탑과 모바일 화면에서 비교할 후보이며, 확정하거나 서비스에 적용한 문구가 아니다. [요구사항](../requirements.md#기기별-사용-경험과-서버-저장)과 [화면 구성 조사](device-specific-note-interactions.md)를 바탕으로 화면 이름, 버튼, 입력란과 상태 문구를 제안한다.

## 공통 탐색

- 메뉴: `메모`, `사용 빈도`, `텍스트 분석`, `템플릿`, `설정`
- 뒤로 가기: `뒤로`
- 메뉴 아이콘의 접근성 이름: `메뉴 열기`

## 로그인과 기기 연결

연결 방식별 후보는 다음과 같다.

- 이메일 로그인 화면: `로그인`
- 이메일 입력란: `이메일 주소`
- 다음 단계 버튼: `계속`
- 확인 코드 입력란: `확인 코드`
- 코드 요청 버튼: `코드 받기`
- 코드 재요청 버튼: `다시 받기`
- 기기 연결 화면: `기기 연결`
- 연결 승인 버튼: `승인`, `거절`
- 승인 대기 상태: `승인 대기 중`
- 연결 재시도 버튼: `다시 연결`

## 데스크탑 메모

- 생성 버튼: `새 메모`
- 본문 입력란: `메모 내용`
- 본문 placeholder: `메모를 입력하세요`
- 빈 메모의 표시 이름: `빈 메모`
- 복사 버튼: `복사`
- 복사 버튼의 접근성 이름: `메모 복사`
- 더보기 버튼의 접근성 이름: `메모 동작`
- 더보기 항목: `속성`, `맨 앞으로`, `맨 뒤로`, `삭제`
- 일괄 복사 버튼: `일괄 복사`
- 일괄 복사 버튼의 접근성 이름: `일괄 복사, {개수}개 항목`
- 빈 목록: `메모 없음`
- 불러오는 상태: `불러오는 중`
- 불러오기 실패 상태: `불러오기 실패`
- 재시도 버튼: `다시 시도`

## 메모 속성

- 패널 제목: `메모 속성`
- 입력란: `X`, `Y`, `너비`, `높이`
- 위치 저장 실패 상태: `위치 저장 실패`
- 크기 저장 실패 상태: `크기 저장 실패`
- 재시도 버튼: `다시 시도`

## 데스크탑 일괄 복사

- 패널 제목: `일괄 복사`
- 항목 수: `{개수}개 항목`
- 빈 목록: `추가한 항목 없음`
- 복사 버튼: `일괄 복사하기`
- 항목 더보기: `복제`, `위로 이동`, `아래로 이동`, `맨 위로 이동`, `맨 아래로 이동`, `삭제`
- 이동 핸들의 접근성 이름: `항목 순서 변경`
- 삭제 버튼의 접근성 이름: `일괄 복사 항목 삭제`
- 순서 저장 실패 상태: `순서 저장 실패`
- 재시도 버튼: `다시 시도`

## 모바일 메모 목록

- 생성 버튼의 접근성 이름: `새 메모`
- 일괄 복사 버튼의 접근성 이름: `일괄 복사, {개수}개 항목`
- 더보기 항목: `복사`, `일괄 복사에 추가`, `수정`, `삭제`
- 더보기 버튼의 접근성 이름: `메모 동작`
- 이동 핸들의 접근성 이름: `메모 순서 변경`
- 빈 목록: `메모 없음`
- 불러오는 상태: `불러오는 중`

## 모바일 메모 수정

- 뒤로 가기의 접근성 이름: `메모 목록으로 돌아가기`
- 편집 도구의 접근성 이름: `실행 취소`, `다시 실행`
- 본문 입력란: `메모 내용`

- 모바일 완료 화면 오른쪽 버튼: `확인`
- 복원 버튼의 접근성 이름: `삭제한 메모 복원`

- 재시도 버튼: `다시 시도`

## 모바일 일괄 복사

- 현재 작업 제목: `일괄 복사`

## 문구 선택의 참고 자료

2026년 11월 4일 기준 자료다. [Microsoft 문구 지침](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style)은 행동을 앞세우고 불필요한 설명을 줄이는 근거다. [GOV.UK 버튼 지침](https://design-system.service.gov.uk/components/button/)은 버튼 이름으로 실행할 행동을 식별하는 데 참고한다. [W3C 상태 메시지 기준](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)은 화면의 상태 문구를 보조 기술에도 전달하는 근거다.
