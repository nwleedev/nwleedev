# 개인 메모 애플리케이션 요구사항

이 애플리케이션은 하나의 사용 흐름과 화면 구성을 유지하면서 백엔드 없이 동작하는 로컬 모드와 계정에 연결된 메모, 누적 텍스트와 템플릿을 동기화하는 계정 모드를 모두 제공해야 한다. 독립적인 웹 애플리케이션으로 실행할 수 있어야 한다. 라이브러리 패키지 빌드와 포트폴리오 웹 애플리케이션 연결은 초기 범위에서 제외한 백로그다. 이 문서는 요구사항 책임자가 요청한 결과를 정리한 기준선이며, 구현 담당자와 검토자는 현재 범위의 각 모드에서 사용자가 완료할 수 있어야 하는 과업과 완료 증거를 확인한다. 조사에서 도출한 구현 제안은 이 문서가 아니라 `references/` 아래 문서에서 다룬다.

## 의도한 결과

- 사용자는 여러 메모를 만들고 각 메모에 텍스트를 입력할 수 있다.
- 사용자는 다른 애플리케이션에서 복사한 텍스트를 애플리케이션에서 만든 메모에 붙여넣을 수 있다.
- 사용자는 모바일 기기가 아닌 넓은 화면에서 메모를 단순 목록이나 그리드에만 배치하지 않고, 공간형 화면에서 각 메모의 위치와 크기를 자유롭게 바꿀 수 있다.
- 사용자는 모바일 기기나 화면 너비가 작은 환경에서 공간형 화면 대신 일반적인 목록 형태로 메모를 확인할 수 있다.
- 사용자는 메모에 URL이나 링크처럼 보이는 문자열을 입력하더라도 다른 텍스트와 같은 방식으로 작성, 편집하고 복사할 수 있다.
- 사용자는 메모의 텍스트 복사 영역을 일반 클릭해 클릭한 메모의 텍스트를 복사할 수 있다.
- 사용자는 여러 메모에서 한 번에 복사하려는 텍스트를 `Command+클릭`해 하나의 텍스트에 누적하고, 별도 화면에서 누적된 텍스트를 확인할 수 있다.
- 사용자는 `Command+클릭`을 사용할 수 없는 환경이나 다른 동작과 충돌하는 상황에 대비해 별도 설정 화면에서 누적 조작 방법을 바꿀 수 있다.
- 사용자는 누적된 텍스트의 순서를 드래그 앤 드롭으로 바꾸고, 특정 텍스트를 누적 텍스트 목록 밖에 놓아 제거할 수 있다.
- 사용자는 잘못 제거한 누적 텍스트를 실행 취소하고, 실행 취소한 제거를 다시 실행할 수 있다.
- 사용자는 텍스트의 일반 클릭 횟수, 누적을 위한 클릭 횟수와 두 횟수의 합계를 별도 화면에서 확인할 수 있다.
- 사용자는 메모 안의 텍스트를 줄바꿈으로 나눈 각 줄이 생김새를 기준으로 서로 얼마나 겹치는지 별도 화면에서 확인할 수 있다.
- 사용자는 생김새가 겹치는 텍스트를 바탕으로 템플릿 텍스트를 제안받을 수 있다.
- 사용자는 텍스트에서 원하는 여러 부분을 플레이스홀더로 표시하고 템플릿으로 만들 수 있다.
- 사용자는 템플릿 텍스트에 필요한 값을 입력해 일회성 텍스트를 만들 수 있다.
- 사용자는 백엔드 없이 동작하는 로컬 모드에서 메모 작성, 편집, 배치, 복사, 누적, 템플릿 생성과 명시적으로 요청한 텍스트 겹침 분석을 사용할 수 있다.
- 사용자는 계정 모드에서 계정에 연결된 메모, 누적 텍스트와 템플릿을 동기화할 수 있다.
- 사용자는 개인 메모 애플리케이션을 독립적으로 실행해 사용할 수 있다.

## 반드시 지킬 조건

- 위 과업은 LLM을 사용하지 않고 완료할 수 있어야 한다.
- 로컬 모드는 애플리케이션 백엔드나 데이터베이스 서버에 연결하지 않아도 동작해야 한다.
- 로컬 모드는 HTTPS URL 또는 호스트 이름이 `localhost`인 HTTP URL로 접속해야 한다. `file://` URL과 `localhost`가 아닌 호스트의 HTTP URL은 지원하지 않아야 한다.
- 로컬 모드의 텍스트 겹침 분석은 사용자가 분석 실행을 명시적으로 요청했을 때만 시작해야 한다.
- 계정 모드는 백엔드와 데이터베이스를 사용할 수 있다.
- 두 모드에서 모두 제공하는 과업은 같은 화면 구조와 조작 방식을 사용해야 한다. 계정 동기화처럼 로컬 모드에서 제공할 수 없는 과업과 그 조작 UI는 로컬 모드에 표시하지 않아야 한다.
- 모바일 기기나 화면 너비가 작은 환경에서는 공간형 메모 화면 대신 일반적인 목록 형태를 제공하고, 메모 작성, 편집, 일반 클릭 복사와 누적 조작을 계속 사용할 수 있어야 한다.
- 메모의 텍스트 복사 영역을 일반 클릭하면 클릭한 메모의 텍스트를 클립보드에 복사해야 한다.
- 메모 본문의 URL이나 링크처럼 보이는 문자열은 일반 텍스트로 취급해야 하며, 초기 범위에서는 자동 링크 변환, 클릭 이동, 미리보기 또는 별도 링크 UI를 제공하지 않아야 한다.
- 클립보드 권한 거부나 쓰기 실패로 복사를 완료하지 못하면 사용자가 실패 원인과 다음 행동을 알 수 있는 알림 UI를 제공해야 한다.
- 메모의 텍스트 복사 영역을 `Command+클릭`하면 클릭한 메모의 텍스트를 누적해야 한다.
- `Command+클릭` 누적은 메모의 텍스트 복사 영역에만 적용하고, 다른 화면으로 이동하는 탐색 항목이나 그 밖의 버튼 동작을 바꾸지 않아야 한다.
- 별도 설정 화면에서 `Command+클릭`을 대신할 누적 조작 방법을 선택할 수 있어야 한다.
- 서로 다른 여러 메모에서 선택한 텍스트를 하나의 누적 텍스트에 추가할 수 있어야 한다.
- 누적 텍스트의 최초 순서는 사용자가 누적 조작을 수행한 순서와 같아야 한다.
- 사용자가 누적된 텍스트를 드래그 앤 드롭하면 놓은 위치에 따라 순서가 바뀌어야 한다.
- 사용자가 누적된 특정 텍스트를 누적 텍스트 목록 밖에 놓으면 드래그한 텍스트가 목록에서 제거되어야 한다.
- 사용자가 누적 텍스트 제거를 실행 취소하면 제거된 텍스트가 이전 위치에 돌아와야 한다.
- 사용자가 실행 취소한 제거를 다시 실행하면 복원됐던 텍스트가 다시 제거되어야 한다.
- 메모 입력 화면과 별도로 누적 텍스트, 텍스트 사용 빈도와 텍스트 겹침을 확인할 수 있어야 한다.
- 사용 빈도 화면은 각 텍스트의 일반 클릭 횟수, 누적을 위한 클릭 횟수와 두 횟수의 합계를 구분해 보여줘야 한다.
- 겹침 분석의 입력 단위는 메모 전체가 아니라 메모의 원문을 줄바꿈으로 나눈 각 줄이어야 한다.
- 생김새가 겹치는 텍스트는 정확한 반복, 포함 관계와 어휘상 근접 반복을 구분할 수 있어야 한다.
- 사용자가 한 템플릿 안의 여러 부분을 플레이스홀더로 지정할 수 있어야 한다.

## 완료를 확인할 증거

- 사용자가 메모를 두 개 이상 만들고 각 메모에 서로 다른 텍스트를 입력할 수 있다.
- 사용자가 다른 애플리케이션에서 복사한 텍스트를 메모에 붙여넣고 붙여넣은 내용을 확인할 수 있다.
- 모바일 기기가 아닌 넓은 화면에서 사용자가 메모 두 개의 위치와 크기를 각각 바꾼 뒤에도 두 메모의 내용과 배치가 유지된다.
- 모바일 기기 또는 브라우저 표시 영역의 너비가 작은 환경에서 메모가 공간형 화면 대신 목록 형태로 표시되고, 사용자가 목록에서 메모를 작성, 편집, 일반 클릭 복사하고 누적할 수 있다.
- 사용자가 메모의 텍스트 복사 영역을 일반 클릭했을 때 클릭한 메모의 텍스트가 클립보드에 복사된다.
- 메모에 URL 형식 문자열을 입력해도 별도 링크 UI가 생기거나 클릭 이동이 실행되지 않고, 일반 클릭하면 URL을 포함한 메모 원문 전체가 복사된다.
- 클립보드 쓰기가 거부되거나 실패했을 때 알림 UI가 실패 사실과 다시 시도하거나 설정을 확인할 방법을 보여준다.
- 사용자가 서로 다른 여러 메모의 텍스트 복사 영역을 `Command+클릭`했을 때 다른 화면으로 이동하지 않고, 별도 화면에서 클릭한 순서대로 누적된 전체 텍스트를 확인할 수 있다.
- 사용자가 설정 화면에서 대체 누적 조작을 선택하면 `Command+클릭` 없이 메모 텍스트를 누적할 수 있다.
- 사용자가 누적된 텍스트의 순서를 드래그 앤 드롭으로 바꾸면 누적된 전체 텍스트에 바뀐 순서가 반영된다.
- 사용자가 누적된 특정 텍스트를 누적 텍스트 목록 밖에 놓으면 드래그한 텍스트가 목록과 누적된 전체 텍스트에서 제거된다.
- 사용자가 방금 제거한 누적 텍스트를 실행 취소하면 이전 위치에 복원되고, 다시 실행하면 같은 텍스트가 다시 제거된다.
- 같은 텍스트를 일반 클릭 두 번, 누적 조작 세 번 했을 때 사용 빈도 화면에 일반 클릭 횟수 2회, 누적을 위한 클릭 횟수 3회와 합계 5회가 표시된다.
- 하나의 메모에 서로 다른 줄을 두 개 이상 입력하고 다른 메모에 그중 한 줄과 겹치는 줄을 입력했을 때, 분석 결과가 메모 전체가 아니라 줄별 관계를 보여준다.
- 정확한 반복, 포함 관계와 어휘상 근접 반복을 각각 준비했을 때 사용자가 별도 화면에서 세 관계를 구분해 확인할 수 있다.
- 생김새가 겹치는 텍스트가 있을 때 사용자가 서로 겹친 텍스트를 바탕으로 한 템플릿 제안을 확인할 수 있다.
- 사용자가 텍스트의 여러 부분을 플레이스홀더로 표시하고 플레이스홀더가 표시된 텍스트를 템플릿으로 만들 수 있다.
- 사용자가 각 플레이스홀더에 값을 입력했을 때 입력한 값이 반영된 일회성 텍스트를 확인할 수 있다.
- 로컬 모드에서 계정이나 동기화 UI가 보이지 않고, 애플리케이션 백엔드 연결 없이 사용자가 분석 실행을 누른 뒤 줄별 겹침 결과를 확인할 수 있다.
- 계정 모드에서 같은 계정으로 연결한 두 브라우저 가운데 한쪽에서 메모를 만들고 수정하거나 삭제하고, 누적 텍스트와 템플릿을 바꾸면 다른 쪽에도 같은 변경이 반영된다.
- 두 모드의 공통 화면을 나란히 비교했을 때 계정 전용 UI를 제외한 정보 구조와 공통 조작이 같다.
- 독립 실행용 빌드 결과를 시작한 뒤 사용자가 메모 작성, 편집, 일반 클릭 복사와 누적 조작을 완료할 수 있다.
- 같은 로컬 정적 빌드 결과를 HTTPS URL과 호스트 이름이 `localhost`인 HTTP URL에서 각각 열었을 때 메모 작성, 편집, 일반 클릭 복사와 누적 조작을 완료할 수 있다.

## 초기 범위에서 제외한 백로그

- LLM을 사용하지 않고 의미가 비슷한 텍스트를 자동으로 판별하는 동작은 초기 개발 범위에 포함하지 않고 후속 개발 항목으로 남긴다.
- 의미가 비슷하다고 판별한 텍스트를 바탕으로 한 템플릿 제안도 후속 개발 항목으로 남긴다.
- 메모 안 URL의 자동 링크 변환, 클릭 이동, 미리보기와 링크 정보 불러오기는 초기 개발 범위에 포함하지 않는다.

### 라이브러리 및 포트폴리오 연결

개인 메모 애플리케이션을 라이브러리 패키지로 빌드하고 포트폴리오 웹 애플리케이션이 선택한 라우트에서 불러오는 작업은 백로그로 남긴다. 현재 구현 범위와 완료 증거에는 라이브러리 빌드 및 포트폴리오 라우트 연결을 포함하지 않는다.

백로그 작업을 시작하기 전에 다음 사항을 정해야 한다.

- 라이브러리 패키지를 같은 저장소의 workspace에서만 사용할지, 별도로 배포해 다른 저장소에서도 설치할 수 있게 할지
- 라이브러리가 지원할 호스트를 Next.js App Router로 제한할지, 다른 React 기반 호스트에서도 사용할 수 있게 할지
- 포트폴리오 웹 애플리케이션이 개인 메모의 단일 라우트만 연결할지, 누적 텍스트, 사용 빈도, 겹침 분석, 템플릿과 설정의 하위 라우트까지 연결할지
- 독립 실행 형태와 포트폴리오 라우트 연결 형태에서 바깥쪽 탐색, 페이지 제목, 테마와 알림 영역 가운데 무엇을 개인 메모 모듈이 그리고 무엇을 호스트가 그릴지
- 포트폴리오 라우트 연결 형태에서 로컬 모드만 제공할지, 계정 모드와 서버 쪽 연결도 함께 제공할지
- 라이브러리 빌드의 공개 진입점, 스타일과 Web Worker 파일 제공 방식 및 호스트 버전 호환 범위

## 확정되지 않은 사항

- 로컬 정적 결과물을 배포할 HTTPS 호스팅과 localhost HTTP 서버의 구현 및 실행 방식
- 로컬과 계정 실행 모드를 빌드 시점 환경변수로 나눌지, 배포 시점 설정으로 나눌지와 기능 가용성을 어떤 단위로 표현할지
- `Command+클릭`을 대신해 설정 화면에서 선택할 조작 방법의 정확한 목록과 기본값
- 메모 입력이나 편집을 위한 클릭과 일반 클릭 복사를 구분할 동작
- 공간형 화면을 무한히 확장할지, 정해진 작업 영역의 크기를 사용자가 바꿀지와 확대, 축소 및 화면 맞춤 동작
- 목록 형태로 전환하는 정확한 화면 너비, 모바일 기기를 별도로 판단할지, 목록 정렬 순서와 넓은 화면으로 돌아왔을 때 기존 공간 배치를 복원하는 방식
- 마우스를 쓰지 않는 키보드 전용 조작과 터치 입력, Command 키가 없는 운영체제에서 제공할 대체 동작
- 누적된 텍스트 사이의 구분자와 같은 텍스트를 여러 번 누적했을 때의 처리 방법
- 실행 취소와 다시 실행 기록을 누적 텍스트 화면을 벗어난 뒤에도 보관할지, 어떤 누적 동작까지 기록할지
- 사용 빈도를 셀 텍스트 단위, 같은 텍스트로 판단하는 규칙, 메모별 또는 전체 횟수 가운데 표시할 값과 클립보드 쓰기 실패를 횟수에 포함할지
- 줄바꿈으로 나눈 빈 줄과 앞뒤 공백을 분석 입력에 포함할지, 대소문자와 유니코드를 비교 전에 어떻게 정규화할지
- 어떤 겹침 유형과 점수 기준을 템플릿 제안에 사용하고 제안이 성립하지 않을 때 무엇을 보여줄지
- 로컬 모드의 메모, 누적 텍스트와 템플릿을 새로고침과 브라우저 종료 뒤에 어떻게 보관하고 백업할지
- 계정 생성과 로그인 방식, 동기화 충돌 해결 규칙, 삭제 전파와 계정 데이터 삭제 범위
