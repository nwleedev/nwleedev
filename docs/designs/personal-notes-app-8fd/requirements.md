# 개인 메모 애플리케이션 요구사항

이 문서는 개인 메모 애플리케이션 개발의 요구사항 기준선이다. [포트폴리오 경력 증거 요구사항](../portfolio-career-evidence-7m4/requirements.md)의 개인 메모 후보 조건을 유지하면서 이번 애플리케이션에서 사용자가 완료할 과업을 구체화한다. 요구사항 책임자는 이 문서를 바탕으로 미확정 동작을 결정하고, 구현 담당자와 검토자는 사용자가 완료할 수 있어야 하는 과업과 완료 증거를 확인한다.

## 의도한 결과

- 사용자는 여러 메모를 만들고 각 메모에 텍스트를 입력할 수 있다.
- 사용자는 다른 애플리케이션에서 복사한 텍스트를 애플리케이션에서 만든 메모에 붙여넣을 수 있다.
- 사용자는 여러 메모에서 한 번에 복사하려는 텍스트를 `특수한 클릭`으로 선택해 하나의 텍스트에 누적하고, 별도 화면에서 누적된 텍스트를 확인할 수 있다.
- 사용자는 텍스트가 얼마나 자주 사용되었는지 별도 화면에서 확인할 수 있다.
- 사용자는 메모의 텍스트가 서로 얼마나 겹치는지 별도 화면에서 확인할 수 있다. 겹침은 의미가 같은 경우와 의미는 다르지만 생김새가 같은 경우를 모두 포함할 수 있다.
- 사용자는 겹치는 텍스트를 바탕으로 템플릿 텍스트를 제안받을 수 있다.
- 사용자는 텍스트에서 원하는 여러 부분을 플레이스홀더로 표시하고 템플릿으로 만들 수 있다.
- 사용자는 템플릿 텍스트에 필요한 값을 입력해 일회성 텍스트를 만들 수 있다.

## 반드시 지킬 조건

- 위 과업은 LLM을 사용하지 않고 완료할 수 있어야 한다.
- 서로 다른 여러 메모에서 선택한 텍스트를 하나의 누적 텍스트에 추가할 수 있어야 한다.
- 메모 입력 화면과 별도로 누적 텍스트, 텍스트 사용 빈도와 텍스트 겹침을 확인할 수 있어야 한다.
- 생김새가 겹치는 텍스트는 정확한 반복, 포함 관계와 어휘상 근접 반복을 구분할 수 있어야 한다.
- 텍스트 겹침은 의미가 같은 경우와 생김새가 같은 경우를 한 종류로 간주하지 않아야 한다.
- 사용자가 한 템플릿 안의 여러 부분을 플레이스홀더로 지정할 수 있어야 한다.

## 완료를 확인할 증거

- 사용자가 메모를 두 개 이상 만들고 각 메모에 서로 다른 텍스트를 입력할 수 있다.
- 사용자가 다른 애플리케이션에서 복사한 텍스트를 메모에 붙여넣고 복사한 내용을 확인할 수 있다.
- 사용자가 서로 다른 여러 메모에서 선택한 텍스트를 하나의 누적 텍스트에 추가하고 별도 화면에서 누적된 전체 텍스트를 확인할 수 있다.
- 반복 횟수가 서로 다른 텍스트를 준비했을 때 사용자가 별도 화면에서 각 텍스트의 사용 빈도를 구분할 수 있다.
- 정확한 반복, 포함 관계와 어휘상 근접 반복을 각각 준비했을 때 사용자가 별도 화면에서 세 관계를 구분해 확인할 수 있다.
- 의미가 같은 텍스트 쌍과 의미는 다르지만 생김새가 같은 텍스트 쌍을 준비했을 때 사용자가 별도 화면에서 두 겹침 유형을 구분해 확인할 수 있다.
- 겹치는 텍스트가 있을 때 사용자가 서로 겹친 텍스트를 바탕으로 한 템플릿 제안을 확인할 수 있다.
- 사용자가 텍스트의 여러 부분을 플레이스홀더로 표시하고 플레이스홀더가 표시된 텍스트를 템플릿으로 만들 수 있다.
- 사용자가 각 플레이스홀더에 값을 입력했을 때 입력한 값이 반영된 일회성 텍스트를 확인할 수 있다.

## 확정되지 않은 사항

- `특수한 클릭`에 사용할 포인터 동작과 키보드 또는 터치 대체 동작
- 텍스트를 누적하는 순서, 텍스트 사이의 구분자와 같은 텍스트를 여러 번 선택했을 때의 처리 방법
- 사용 빈도를 셀 텍스트 단위, 같은 텍스트로 판단하는 규칙과 메모별 또는 전체 횟수 가운데 표시할 값
- 의미가 같은 텍스트를 애플리케이션이 자동으로 판단해야 하는지, 사용자가 같은 의미라고 확인한 텍스트 관계를 포함할 수 있는지와 어느 정도의 오탐 및 누락을 허용할지
- LLM을 사용하지 않는다는 조건에서 사전, 규칙 기반 분석이나 LLM이 아닌 로컬 모델을 허용할지 여부
- 어떤 겹침 유형을 템플릿 제안에 사용하고 제안이 성립하지 않을 때 무엇을 보여줄지
- 메모, 누적 텍스트와 템플릿을 새로고침, 브라우저 종료와 다른 기기에서 각각 보관할지
