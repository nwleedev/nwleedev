# 이미지와 메모 속성의 조작 방식

사진과 메모의 위치와 크기는 캔버스에서 바로 조절하고, 정확한 위치나 치수가 필요할 때는 숫자로 입력하는 방식을 시안에서 비교한다. 품질은 미리보기를 보며 조절하고, 형식과 방향은 정해진 선택지에서 고르는 편이 적합하다. 아래 조작은 비교할 후보이며 시안 검토에서 배치와 표현을 판단한다.

## 조사 근거

- W3C는 드래그 조작에 클릭이나 탭만으로 쓸 수 있는 대안을 설명하며 숫자 입력도 가능한 대안으로 든다. 키보드 조작도 별도로 확인해야 한다. [WCAG 2.2 드래그 기준 해설](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements)
- GNOME은 범위 안에서 대략적인 값을 고르는 데 슬라이더를 쓰고, 정확한 값도 필요하면 숫자 입력을 연동하는 방식을 제시한다. [GNOME 슬라이더 지침](https://developer.gnome.org/hig/patterns/controls/sliders.html)
- Apple은 값을 조금씩 바꿀 때 증감 버튼을 쓰고, 큰 폭의 변경이 필요할 때는 입력칸을 함께 고려하라고 안내한다. [Apple 증감 버튼 지침](https://developer.apple.com/design/human-interface-guidelines/steppers)

세 자료는 2026년 11월에 확인했다. 플랫폼 지침은 후보를 고르는 근거로 썼으며 캔버스에서의 사용성은 직접 조작해 확인해야 한다.

## 속성별 후보

- 이미지 위치는 이미지 본문을 드래그한다. 드래그 없이 위치를 바꿀 때는 X와 Y를 직접 지정한다.
- 이미지 배치 크기는 모서리를 드래그하고, 정확한 크기는 너비를 입력한다. 높이는 원본 비율에 따라 바뀐다. 원본 크기는 한 번의 버튼 조작으로 복원한다.
- 메모 방향은 네 방향 버튼으로 고른다. 메모의 너비와 높이는 드래그로 조절한다. 정확한 치수를 입력하는 방법도 후보로 둔다.
- 개별 이미지 품질과 JPG 저장 품질은 각각 미리보기와 슬라이더를 둔다. 품질 값의 의미와 조절 방식은 실제 내보내기 정책을 정한 뒤 확정한다.
- 전체 저장 여백은 0px부터 24px까지 1px씩 증감할 수 있게 한다. 형식과 선택 영역 모양은 이름이 보이는 선택지로 제공한다.
