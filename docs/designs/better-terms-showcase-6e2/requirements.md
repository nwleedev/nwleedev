# use-better-terms 쇼케이스 요구사항

`use-better-terms` 스킬이 글의 표현을 어떻게 검토하고 다듬는지 방문자가 직접 이해할 수 있는 소개 페이지 또는 웹사이트를 만든다. 준비된 문서 예시를 활용해 적용 전후를 직관적으로 비교할 수 있어야 한다.

## 방문자가 확인할 내용

- 방문자가 예시의 적용 전 문구와 적용 후 문구를 직접 비교할 수 있어야 한다.
- 방문자가 파일을 직접 올리는 방식보다 준비된 예시를 살펴보는 방식을 우선한다.
- 기존 개발자 소개 사이트를 활용하는 경우 현재 레이아웃을 크게 바꾸지 않는다.

## 완료를 확인할 방법

- 방문자가 사이트 화면에서 준비된 예시의 적용 전후를 확인하고 차이를 설명할 수 있다.
- 기존 사이트에 추가한다면 개발자 소개 화면의 현재 배치가 크게 달라지지 않았는지 비교할 수 있다.

## 결정할 사항

쇼케이스를 별도 사이트로 만들지, 기존 개발자 소개 사이트에 페이지를 추가할지 검토한 뒤 선택해야 한다. 기존 사이트에 페이지를 추가하려면 [개발자 소개 사이트 요구사항](../developer-portfolio-f4b7/requirements.md#한-페이지의-정보-순서)의 단일 페이지 구성 및 내부 상세 페이지 제외 결정을 함께 확인해야 한다.
