# 홈페이지에 연결할 프로젝트와 블로그 글

개인 메모 앱과 Issnuta를 차례로 소개하고, React 상태 초기화 글과 AI 작업 맥락 글을 함께 연결하는 구성을 제안한다. 문장을 다시 사용하는 과정의 화면 설계, 인터넷 연결 없이 번역하기 위한 기술 선택, 구현 원리와 개발 방법을 살피는 태도를 각각 보여줄 수 있기 때문이다. 이 순서와 게재 목록은 아직 확정하지 않았다.

현재 방문자가 사용할 수 있는 서비스는 없으며, [제작 내용을 먼저 소개하는 결정](../decisions/project-availability.md)에 따라 서비스 준비 후 이용 링크를 추가한다.

이 문서는 [홈페이지 구성](../requirements.md#홈페이지)을 정하기 위한 자료다. 2026년 9월 15일 개인 메모 앱의 Git 기록과 구현, GitHub CLI로 [Issnuta 저장소](https://github.com/nwleedev/issnuta)의 설명과 README를 확인했다. Codex 앱 브라우저에서는 [기존 블로그](https://blog.nwlee.com/)의 목록과 아래 두 글의 본문을 읽었다. 전체 프로젝트와 글의 우선순위를 평가한 것은 아니며, 현재 소개 방향을 보충할 후보를 선정했다.

## 프로젝트 후보: 개인 메모 앱

프로젝트 중 첫 번째로 소개할 것을 권한다. [개발자 소개](developer-introduction.md)의 사용자 이해와 화면 설계를 가장 직접적으로 뒷받침하기 때문이다. 문장을 다시 사용하는 목적을 기준으로 원문과 선택한 문장의 배치, 휴대전화에서의 선택과 편집, 작성한 내용의 보존을 함께 판단한 경험이다. [개발 목적과 Git 근거](personal-notes-project.md)에 초기 요구사항, 화면 구성의 이유와 실제 수정 사항을 구분해 정리했다.

홈페이지 설명 초안:

> 반복해서 사용하는 문장을 모으고, 필요한 내용만 조합해 다시 쓰는 개인 메모 앱을 개발하고 있습니다.

상세에서는 문장을 다시 사용한다는 목적 때문에 어떤 설계 기준을 세웠는지 설명한다. [테스트 경험의 활용 판단](personal-notes-testing.md)은 내용 보존을 확인하는 기준으로 연결하며, 편집과 저장의 수정 내역이나 검사 항목을 홈페이지 소개에 추가하지 않는다. 현재 제공하지 않는 계정 동기화나 의미 유사성 자동 판별은 소개에 넣지 않는다. 게재 여부와 외부에서 열람할 소스 주소는 아직 정하지 않았다.

## 프로젝트 후보: Issnuta

개인 메모 앱 다음에 소개하면 화면 구성의 판단에서 기술 선택의 판단으로 관심을 이어갈 수 있다. 인터넷 연결이 없는 조건에서도 번역할 수 있도록 브라우저에서 번역 모델을 실행한다는 점이 소개 방향을 뒷받침한다.

2026년 9월 15일 확인한 [한국어 README](https://github.com/nwleedev/issnuta/blob/f9b75720ee22fb142d821438227ac4dac8e1e95b/README.ko.md)는 프로젝트를 “모바일 우선 오프라인 번역 PWA”로 소개한다. 먼저 선택한 언어의 모델을 내려받아 저장한 뒤, 인터넷 연결 없이 번역할 수 있다고 설명한다. 한국어와 영어, 한국어와 일본어 사이의 번역을 제공한다.

홈페이지 설명 초안:

> 인터넷 연결 없이도 번역할 수 있도록 만든 웹 애플리케이션입니다. 필요한 번역 모델을 미리 저장하면 한국어와 영어, 한국어와 일본어 사이의 번역을 지원합니다.

상세에서는 번역할 때 인터넷 연결이 필요하지 않도록 브라우저 실행 방식을 선택했다는 이유를 먼저 설명한다. 모델을 미리 받아야 한다는 사용 조건도 함께 제공한다. 이력서의 오프라인 번역 경험과 연결해 소개할 수 있는 후보지만, 첫 버전 게재 여부는 아직 정하지 않았다.

소스 코드는 외부에서 열람할 수 있다. 저장소의 홈페이지 주소 항목은 비어 있고 README에는 로컬 실행 방법이 있어, 이 자료만으로 배포된 서비스의 접속 주소나 현재 동작을 확인할 수는 없다. 저장소 자료만으로 현재도 개발을 진행하는지 판단하지 않는다. 게재가 정해지면 실제 개발 상태에 맞는 표시를 확인한다. 서비스 링크를 추정하거나 소스 코드 링크를 서비스 이용 링크로 대신하지 않는다.

AI 작업 문서 도구와 일기 관리 및 분석 서비스도 [이력서에서 확인한 후보](content-and-site-direction.md#첫-소개와-프로젝트)다. 개인 메모 앱과 일기 관리 팀 프로젝트는 서로 다른 프로젝트로 구분한다.

## Key를 활용하여 컴포넌트 상태를 초기화하기

글 중 첫 번째로 소개할 것을 권한다. 검색 조건의 변화에 맞춰 상태를 초기화하는 방법을 React의 원리와 연결해 판단하는 글이므로 프론트엔드 전문성을 먼저 보여줄 수 있다.

2025년 9월 21일 발행한 [글 원문](https://blog.nwlee.com/use-react-keys-to-reset-components)은 URL 검색 조건이 바뀌어도 자식 컴포넌트의 상태가 유지되는 상황을 설명한다. “동일한 위치에 있는 컴포넌트는 상태가 보존된다”는 원리에서 출발해, Effect에서 상태를 변경하는 방법과 `key`로 상태를 초기화하는 방법을 비교한다. 본문은 2026년 9월 15일 확인했다.

홈페이지 설명 초안:

> 검색 조건이 바뀌어도 이전 상태가 남는 이유를 React의 상태 보존 방식으로 살펴보고, 초기화 목적에 맞는 구현 방법을 비교합니다.

이 글을 소개하면 대표 사례의 SharedWorker나 SSE 경험 외에도 프레임워크의 기본 원리를 이해하고 적용하는 관심을 보여줄 수 있다. 실제 제목과 링크를 사용하며, 사례에 없는 성능 수치나 라이브러리 전문성을 추가하지 않는다.

## AI 에이전트에서 작업 맥락을 관리하기 위해 사용한 방법

React 글 다음에 소개할 것을 권한다. 구현 방법뿐 아니라 개발을 이어가는 방식에서도 반복되는 문제를 발견하고 대안을 조정하는 태도를 보여줄 수 있다.

2026년 3월 8일 수정한 [글 원문](https://blog.nwlee.com/codex-work-context-maintainance)은 긴 작업에서 목표와 결정 사항을 놓치는 문제를 설명한다. “이미 결정된 방식에 대해서 고민하거나 번복한다”는 문제를 제시하고, 데이터베이스와 파일을 사용한 방법을 비교한다. 계획, 결정, 진행 상황과 조사 기록을 나누어 작업별로 관리한 경험이 담겨 있다. 본문은 2026년 9월 15일 확인했다.

홈페이지 설명 초안:

> AI와 개발을 이어갈 때 목표와 결정 사항을 다시 확인할 수 있도록, 필요한 기록을 구분해 관리하는 방법을 소개합니다.

도구를 사용한다는 사실에 더해 반복되는 문제를 발견하고 기록 방식을 개선한 판단을 보여주는 후보다. 본문에 실린 당시의 스크립트를 현재 사이트의 구현 방식으로 채택한다는 뜻은 아니다.

## 게재 결정과 문구 관리

프로젝트는 개인 메모 앱과 Issnuta를 함께 소개하는 구성과 개인 메모 앱만 소개하는 구성을 비교한다. 두 프로젝트를 소개하면 사용자의 목적에 맞춰 화면 구성과 브라우저 기술을 선택한 경험을 함께 보여준다. 개인 메모 앱만 소개하면 문장 재사용이라는 목적에서 시작한 설계 판단을 집중해서 설명할 수 있다. 현재 추천은 개인 메모 앱, Issnuta 순서다.

글은 두 편을 함께 소개하는 구성과 React 글만 소개하는 구성을 비교한다. 두 글은 프론트엔드 동작 이해와 개발 방법의 개선을 함께 보여주고, React 글만 소개하면 홈페이지의 초점을 프론트엔드 구현에 더 집중할 수 있다. 현재 추천은 React 글, AI 작업 맥락 글 순서다. AI 도구의 사용 자체가 소개의 중심이 되지 않도록 구현 원리를 설명하는 글을 먼저 둔다.

글의 제목과 Issnuta는 원문 및 저장소를 식별하는 이름으로 유지하고, 홈페이지 설명은 수정 가능한 한국어 초안으로 관리한다. 프로젝트의 게재 방식과 최종 목록, 글의 선정 및 배치는 한국어 콘텐츠 구성에서 정한 뒤 플랜에 반영한다.

서비스 준비 전에도 개발 상태와 상세 설명을 제공한다. 이용 링크가 없다는 이유로 프로젝트 영역을 생략하거나 실제 접속할 수 없는 주소를 넣지 않는다. 서비스 준비 후 이용 링크를 추가하는 절차는 [프로젝트 제공 결정](../decisions/project-availability.md#제작과-완료-확인에-미치는-영향)을 따른다.
