# 편집형 시각 방향과 디자인 기준

사이트의 시각 방향은 `Technical Publication / Career Index / Evidence-driven`으로 정한다. 밝은 바탕, Pretendard, 제한된 분홍색 강조, 비대칭 편집 배치와 문맥 안의 수치를 사용해 개발자의 경력과 기술적 기여를 한 편의 기술 출판물처럼 구성한다.

이 결정은 [편집형 시각 규칙](../requirements.md#편집형-시각-규칙), [글꼴과 글자 체계](../requirements.md#글꼴과-글자-체계), [색상](../requirements.md#색상)과 [여백과 반응형 배치](../requirements.md#여백과-반응형-배치)에 적용한다. 공식 자료와 실제 사이트를 대조한 내용은 [편집형 디자인 조사](../references/editorial-design-system.md)에 있다.

## 비교한 방향과 선택 이유

프로젝트 화면을 앞세우는 포트폴리오 구성과 회사 기여를 편집한 기술 프로필 구성을 비교했다. 첫 번째 방식은 독립 애플리케이션의 UI를 빠르게 보여줄 수 있지만, 현재 자료에서 가장 강하게 확인되는 운영 대시보드, 장시간 비동기 작업, 브라우저 처리와 E2E 검증 경험을 회사 화면 없이 설명하기 어렵다.

기술 프로필 구성은 회사별 Engineering Contribution, 수치, 기술 정보와 외부 기여를 같은 페이지에서 이어 읽게 한다. 회사 내부 화면을 추정하지 않고도 문제, 판단과 결과를 보여줄 수 있으며 단일 페이지 소개와 블로그의 역할도 구분할 수 있어 선택했다.

## 반복할 시각 특징

- 연도, 회사와 기술 맥락을 본문보다 낮은 위계의 여백 정보로 둔다.
- 수치는 별도 성과판이 아니라 수치가 나온 기여의 설명 옆에서 강조한다.
- 오픈소스와 배경 정보는 빠르게 훑을 수 있는 행으로 제공한다.
- 얇은 구분선과 `#EE5166` 계열의 제한된 강조를 반복한다.
- 글자 크기, 굵기, 여백과 정렬을 색보다 먼저 사용한다.

## 확정한 시작값

- 글꼴: `Pretendard Variable`, `Pretendard`, `system-ui`
- 기본 바탕: `#FFFFFF`
- 주요 본문: `#18181B`
- 브랜드 기준색: `#EE5166`
- 일반 브랜드 글자와 링크: `#C62A44`
- 마우스를 올리거나 누른 링크: `#B4233C`
- 내용 최대 폭: 1200px
- 좌우 여백: `clamp(1rem, 3vw, 2rem)`
- 페이지 구성 전환 검토값: 약 48rem과 70rem
- 여백 값: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`

시작값은 요구사항으로 채택했지만 실제 한국어 줄바꿈과 접근성을 해치면 조정할 수 있다. 조정한 값과 이유는 구현과 일치하는 `DESIGN.md`에 기록한다.

## 사용하지 않는 표현

첫 버전에는 3D 물체, 가짜 회사 화면, 전체 화면 Hero, 반복되는 큰 둥근 카드, Bento grid, 기술 로고 모음, 별도 성과판, 가짜 터미널, 계속 움직이는 배경과 모든 영역의 등장 애니메이션을 사용하지 않는다.

어두운 테마, 보조 고정폭 글꼴, 삽화 체계와 복잡한 움직임은 현재 필요가 없어 정하지 않는다. 이후 실제 요구가 생기면 이 결정과 접근성 및 성능 조건을 함께 다시 검토한다.
