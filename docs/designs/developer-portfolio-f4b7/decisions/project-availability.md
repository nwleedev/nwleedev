# 첫 버전의 독립 작업 선정

첫 버전에는 **AI Agent Workflow**와 **Offline Translation Web App**을 Independent Work로 소개한다. 회사 경력과 다른 형식으로 실제 작업의 목적, 확인된 결과와 기술 정보를 제공한다.

이 결정은 [Independent Work](../requirements.md#independent-work)와 [한 페이지의 정보 순서](../requirements.md#한-페이지의-정보-순서)에 적용한다. 개인 메모 앱과 일기 관리 및 분석 팀 프로젝트는 첫 버전의 필수 소개 항목에서 제외한다.

## 비교한 구성과 선택

개인 메모 앱과 Issnuta를 함께 보여주는 기존 구성과, 현재 자료에서 구현 내용 및 운영 조건을 더 구체적으로 확인할 수 있는 두 독립 작업을 보여주는 구성을 비교했다.

AI Agent Workflow는 요구사항, 조사, 결정과 구현을 나누는 작업 방식과 한국어 문구 검사를 보여준다. Offline Translation Web App은 브라우저 캐시, Web Worker, IndexedDB와 배포 자동화로 네트워크가 없어도 번역을 실행한 경험을 보여준다. 두 항목은 회사 Experience와 겹치지 않으면서 저장소 작업 방식과 독립 애플리케이션 개발을 함께 설명할 수 있어 선택했다.

개인 메모 앱은 개발 중인 목적과 기능은 확인했지만 첫 버전의 경력 중심 정보 순서에서는 우선순위가 낮다. 일기 관리 및 분석 팀 프로젝트는 리더십이나 QA 설명이 추가로 필요할 때 이력서에서 확인할 수 있으므로 홈페이지의 필수 항목으로 두지 않는다.

## 링크와 수치 사용

실제 이용 주소와 외부에서 열람 가능한 소스 주소가 있을 때만 링크를 표시한다. 주소가 없으면 비활성 버튼이나 빈 자리를 만들지 않는다.

Offline Translation Web App의 `30초 이내 배포`는 비교 조건과 근거를 확인한 뒤에만 사용한다. 확인하기 전에는 작업 목적과 구현 내용만 소개한다. AI Agent Workflow는 실제로 적용한 저장소 규칙, Skill과 검사 도구만 설명하고 효과를 측정한 것처럼 표현하지 않는다.

새로운 독립 작업을 추가할 때에는 기존 두 항목과 다른 판단 또는 확인 가능한 결과를 보태는지 먼저 검토한다. 프로젝트 수를 맞추기 위해 항목을 추가하지 않는다.
