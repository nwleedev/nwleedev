# 엔티티 식별 정보

이 모듈은 엔티티 ID와 밀리초 정수 타임스탬프를 검증하고 이전 ISO 시각을 현재 저장 형식으로 변환한다. 빈 식별자, 정수가 아닌 시각과 JavaScript Date 범위를 벗어난 시각을 거절한다. 이전 시각의 밀리초 미만 자릿수는 버린다.

ISO 시각과 revision 검증은 이전 저장 자료를 읽는 데이터 이전 코드에서 사용한다. revision은 0 이상의 안전 정수여야 한다. 현재 메모에 revision 칼럼을 추가하는 규칙이 아니다.

메모 변경 규칙, 저장 방식과 ID 생성은 각 기능에서 관리한다.
